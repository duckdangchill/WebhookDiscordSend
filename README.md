# WebHook Discord Send 🚀

Trang web tĩnh gọn nhẹ dùng để gửi văn bản, liên kết từ máy ảo / VPS Cloud về Discord qua Webhook.

---
### ✨ Tính năng nổi bật

* **Gửi Tệp, Ảnh & Video:**
  * Kéo thả hoặc duyệt file dễ dàng (hỗ trợ mọi định dạng: `.png`, `.jpg`, `.mp4`, `.zip`, `.log`, `.txt`...).
  * **Chụp màn hình dán ảnh ngay:** Nhấn `Ctrl + V` bất kỳ đâu trên trang web để tự nạp ảnh chụp màn hình từ clipboard.
  * Tự động tính toán dung lượng đính kèm (giới hạn tối đa 25MB theo tiêu chuẩn Discord).
  * Xem trước ảnh thumbnail, thông tin kích thước và nút gỡ tệp nhanh.
* **Gửi Văn bản theo thiết bị:**
  * 📱 **Điện thoại:** Bọc dạng `` `văn bản` `` (tiện bấm giữ copy trên Discord mobile).
  * 💻 **Máy tính:** Bọc dạng ```` ```văn bản``` ```` (sẵn nút copy 1-click trên Discord desktop).
  * Có thể gửi riêng văn bản, riêng tệp/ảnh hoặc gửi kết hợp cả hai cùng lúc.
* **Lưu Webhook tự động:** Nhập link Webhook Discord một lần, trình duyệt tự lưu vào `localStorage`. Khi cần đổi chỉ cần bấm nút `Đổi / Xóa`.
* **Nhật ký gửi gần đây (Session History):** Xem lại nhanh các lượt gửi gần nhất để chắc chắn file/tin nhắn đã được gửi đi thành công.
* **Giao diện Tactile Dark Neumorphism:** Tông xám than cao cấp (`#121418`), có chiều sâu với lưới dot-matrix tinh tế, thanh thông số (specs strip) chuyên nghiệp, không trống trải, không dùng màu neon loè loẹt.
* **100% Miễn phí:** Hoạt động hoàn toàn trên GitHub Pages, gửi trực tiếp từ client lên Discord Webhook (không cần mua hosting hay domain).
